Robust enterprise web application engineered at **Asmita Solutions** for automated employee onboarding, identity workflows, and role-based data governance using **Angular**, **Spring Boot**, and **MySQL**.

# Architectural Highlights

- **Modern Angular Frontend**: Developed an intuitive, accessible interface featuring dynamic multi-step onboarding forms, real-time client-side validation, and responsive layouts.
- **RESTful Spring Boot Backend**: Designed clean, decoupled Spring Boot controllers, services, and repositories following SOLID principles and Clean Architecture.
- **Relational Data Modeling**: Architected normalized MySQL schemas supporting audit logging, relational integrity, and transaction management.
- **Collaborative UI/UX**: Partnered directly with product stakeholders to design UI/UX patterns and ensure seamless integration across a 2-month production lifecycle.
- **End-to-End Delivery**: Handled development from requirements and database design through API testing and deployment.
