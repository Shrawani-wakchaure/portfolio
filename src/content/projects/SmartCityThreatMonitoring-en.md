Architecture and implementation of an end-to-end **4-layer cybersecurity framework** (Perception, Communication, Processing, Security) tailored for urban **smart city IoT traffic infrastructure**, actively simulating and mitigating **DDoS, spoofing, and malware attack scenarios**.

# Key Capabilities & Architecture

- **Multi-Layer Defense System**: Designed a comprehensive 4-layer architecture ensuring robust telemetry security across edge sensors, MQTT message brokers, and centralized monitoring nodes.
- **Machine Learning Threat Detection**: Implemented an **Isolation Forest ML model** targeting **85–95% anomaly detection accuracy**, assigning dynamic risk scores (**Low / Medium / High / Critical**) to incoming MQTT traffic packets to eliminate manual triage overhead.
- **Forensic Log Integrity**: Engineered **SHA-256 hashed blockchain-logged security alerts** to guarantee tamper-proof audit trails for forensic validation.
- **Automated SIEM Engine**: Integrated custom **SIEM correlation rules** for continuous automated detection of failed authentications, brute-force bursts, and unauthorized device access.
- **Live Streamlit Security Operations Center**: Built a real-time interactive dashboard visualizing live threat feeds, attack timelines, packet latency, and risk distribution across simulated urban IoT traffic nodes.
