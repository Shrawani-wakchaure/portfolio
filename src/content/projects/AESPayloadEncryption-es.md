Sistema de seguridad criptográfica desarrollado en **Asmita Solutions** para garantizar el **cifrado de carga útil con AES de extremo a extremo** entre una aplicación Angular y un backend Spring Boot.

# Aspectos Técnicos Destacados

- **Criptografía de Carga Útil Bidireccional**: Servicios de cifrado en Angular e interceptores HTTP para cifrar solicitudes y descifrar respuestas de forma transparente.
- **Filtros de Descifrado en Backend**: Cadenas de filtros en Spring Boot para procesar payloads cifrados y validar la integridad de los datos.
- **Protección de Superficie API**: Rediseño de endpoints eliminando identificadores expuestos en URLs y parámetros de consulta.
- **Mitigación de Vulnerabilidades**: Prevención activa contra ataques MITM, manipulación de parámetros, XSS y CSRF.
- **Validación con Insomnia**: Pruebas y depuración exhaustiva de APIs seguras garantizando máxima interoperabilidad.
