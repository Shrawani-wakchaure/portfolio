# Core Methodologies & Results

- **Time-Series Modeling**: Implemented **AutoRegressive (AR) time-series forecasting models**, improving projection accuracy by **15%** over baseline models.
- **Exploratory Data Analysis (EDA)**: Conducted deep distribution analysis, correlation studies, and trend decomposition on complex datasets to translate mathematical findings into actionable insights.
- **End-to-End Pipeline**: Built Python data ingestion, cleansing, feature engineering, and normalization routines utilizing **pandas** and **NumPy**.
- **Data Visualization**: Designed informative visual plots and diagnostic charts using **matplotlib** and **seaborn** to communicate trends effectively to cross-functional teams.
- **Statistical Model Evaluation**: Validated performance metrics and monitored residuals to prevent overfitting and guarantee dependable forecasts.
